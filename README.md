# U.S. States Guessing Game 🇺🇸

An interactive Python game where you try to guess all 50 U.S. states on a map.

## Technologies

* Python
* Turtle
* Pandas
* CSV

## Features

* Interactive U.S. map
* Tracks guessed states
* Displays correct guesses on the map
* Saves missing states to `states_to_learn.csv`

## How to Run

```bash
pip install pandas
python main.py
```

Make sure `50_states.csv` and `blank_states_img.gif` are in the project folder.
